4. Bảng tóm tắt Class & Trách nhiệm

ClassTrách nhiệm chínhQuan hệ
UserXác thực, phân quyền (Admin / Manager / Inspector)1..* Project, 1..* DailyInspection, 1..* AuditLog
ProjectĐại diện một dự án; chứa cấu kiện, mapping, lịch sử kiểm tra1..* Component, 1..* ColumnMapping, 1..* DailyInspection
ColumnMappingLưu ánh xạ cột Excel → trường hệ thống, theo từng dự án (MASTER hoặc DAILY)n..1 Project
ComponentCấu kiện cần nghiệm thu; lưu thông tin và trạng thái mới nhấtn..1 Project; được cập nhật bởi InspectionRecord
DailyInspectionMột lần import file Excel kiểm tra trong ngàyn..1 Project, 1..* InspectionRecord
InspectionRecordMột dòng kiểm tra (1 cấu kiện) trong file ngày → áp lên Componentn..1 DailyInspection → 1 Component
AuditLogGhi mọi hành động (ai, làm gì, lúc nào) để truy vếtn..1 User
ReportSinh báo cáo tiến độ nghiệm thu theo dự án (Excel/PDF)n..1 Project
